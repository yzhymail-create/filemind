# FileMind V1 — Windows 10 使用说明（免管理员）

> 全程不需要管理员权限。所有操作只读写你自己的用户目录。

## 启动方式：双击就行（二选一）

1. 解压 zip，打开 `filemind_v1` 文件夹。
2. 没装 Python 的话先去 python.org 装个 3.8 以上 64 位版（安装勾选 Add to PATH）；装了就跳过。
3. 双击启动：
   - **`start_desktop.bat`**（推荐）：打开原生桌面窗口，不用浏览器；首次运行会弹出图形界面让你点选文件夹，不用手打路径。Windows 上需要 WebView2（Win10/Win11 一般自带）。
   - **`start_filemind.bat`**：浏览器版，自动打开 http://127.0.0.1:8901（只在本机访问，不联网）。

两个 BAT 都会自动：找 Python → 装依赖 → 首次引导 → 启动。想退出：关闭窗口即可（桌面版关窗口即退出；浏览器版关闭那个黑窗口即退出）。

**首次运行**：桌面版用鼠标点选文件夹（可多选）；浏览器版手动输入路径（多个用英文逗号隔开，例如 `D:\工作资料,D:\项目文档`）。
建议先拿一个小文件夹试，确认没问题再加正式目录（界面"扫描"页也可以随时添加）。

小技巧：不想要黑窗口，可以建一个 VBS 文件（英文名，如 `launch_hidden.vbs`），内容两行：
```vbs
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "cmd /c start_desktop.bat", 0, False
```
双击 VBS 即无窗口启动（注意：依赖安装失败时也看不到报错，首次先用 BAT 确认能跑）。

## 界面上有 5 个入口

| 入口 | 用来干什么 |
|---|---|
| **首页** | 顶部是搜索框；下面是**待处理事项**：需确认的版本链、重复文件待清理、失踪文件、疑似改名，一眼看清 |
| **搜索** | 输入你记得的**内容**（不是文件名），如 `线束阻燃 胶带`；支持时间词：`去年 线束方案`、`近30天 确认版`。结果按版本链聚合，直接给推荐版本 |
| **版本链** | 点进一条链看时间轴：`设为可用版`（人工置顶最强）、`确认这条链正确`、`移出本链`（算法分错了就拆）、任选两版`比较`看差异（Windows 上还有`打开`/`文件夹`按钮） |
| **重复文件** | 指纹完全相同的文件分组。建议保留项已勾好并解释原因，你确认后点按钮，**其余副本进 Windows 回收站**（可还原） |
| **扫描** | 文件有新增/修改后点"开始扫描"同步；这里也能看到失踪文件列表和疑似改名/移动，并添加新的监控目录 |

## 安全承诺

- 原始文件**不移动、不改名**；版本链/置顶/确认都只是数据库里的标记。
- 删除只进 **Windows 回收站**，不彻底删除，可还原；进回收站失败会明确报错，不会偷偷把文件挪到别处。
- 所有认知数据只存在 `data\filemind.sqlite` 一个文件里；删掉解压目录即卸载干净。
- 无网络、无 AI、无账号，全部本地运行。

## 常见问题

- **双击 BAT 一闪而过**：右键 BAT → 编辑，确认是 UTF-8 with BOM 编码；或在 cmd 里手动运行看报错。
- **BAT 说没找到 Python，但我明明装了**：新版 BAT 会先查 PATH，再翻常见安装位置（`%LOCALAPPDATA%\Programs\Python\`、`C:\Python3*` 等），并跳过微软商店的占位程序；还找不到会让你手动输入 python.exe 所在文件夹，记住位置下次直接用。都不行才需要重装（安装时勾选 Add to PATH）。你的 Python 3.8 以上就能用，不用为了这个升级。
- **`pip install` 失败**：检查网络；公司内网可能需要配 pip 镜像源。
- **启动时报 FTS5+trigram 不可用**：换一个 Python 发行版（如 python.org 官方版），Windows 自带/微软商店版有时缺这个。
- **端口 8901 被占用**：说明 FileMind 已在运行，BAT 会直接帮你打开浏览器，不会重复启动。

## 命令行备选（BAT 出问题时用）

```bat
cd /d <解压目录>\filemind_v1
python -m pip install --user -r requirements.txt
python -m filemind.main init --db data\filemind.sqlite --dirs D:\工作资料
python -m filemind.main scan --db data\filemind.sqlite
python -m filemind.main serve --db data\filemind.sqlite
```

## 已知局限（V1）

- 扫描版 PDF（图片型）只记录"需 OCR"，不做文字识别。
- 文本差异看不出字体/字号/排版变化。
- 语义搜索（"找以前讨论过阻燃问题的文件"）是 V2 功能，V1 只做关键词+时间。
