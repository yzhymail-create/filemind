# FileMind - 本地文件记忆与版本管理工具

FileMind 是一款纯本地运行的文件管理工具，帮助你追踪文件版本、查找重复文件、按内容搜索文件。

## 特性

- **纯桌面应用**：基于 CustomTkinter，无需浏览器，双击即可运行
- **版本链管理**：自动识别同一文件的不同版本（如"方案V1"、"方案V2"）
- **重复文件检测**：通过 SHA256 指纹识别完全相同的文件
- **内容搜索**：支持按文件内容搜索（支持 docx/xlsx/pptx/pdf/txt）
- **文件夹监控**：选择要监控的文件夹，自动扫描变化
- **纯本地运行**：所有数据存储在本地 SQLite 数据库，不联网

## 快速开始

### 1. 安装依赖

需要 Python 3.8+，然后运行：

```bash
pip install -r requirements.txt
```

### 2. 启动程序

**Windows 用户**：双击 `start_filemind.bat`

**命令行启动**：
```bash
python -m filemind.main gui --db data/filemind.sqlite
```

### 3. 首次使用

1. 程序启动后，点击左侧"文件夹"
2. 点击"添加文件夹"，选择要监控的目录
3. 切换到"扫描"页面，点击"开始扫描"
4. 扫描完成后，可以在"搜索"、"版本链"、"重复文件"页面查看结果

## 功能说明

### 文件夹管理
- 添加/删除监控目录
- 支持多个目录同时监控

### 文件扫描
- 扫描监控目录下的所有文件
- 提取文件内容（支持多种格式）
- 计算文件指纹（SHA256 + SimHash）
- 显示扫描进度和日志

### 内容搜索
- 按关键词搜索文件内容
- 支持时间词（去年/今年/近30天）
- 搜索结果按相关度排序

### 版本链
- 自动识别同一文件的不同版本
- 通过文件名去噪 + 内容指纹判断
- 显示推荐版本（最新/最大/最完整）
- 支持手动确认或拆分版本链

### 重复文件
- 检测 SHA256 完全相同的文件
- 分组显示重复文件
- 支持批量删除（移入回收站）

## 支持的文件格式

- **文档**：docx, pdf, txt, md
- **表格**：xlsx, csv
- **演示**：pptx
- **其他**：lsp, bas, py, js, ini, cfg, json, xml

不支持的格式会记录文件名和大小，用于重复检测。

## 数据存储

所有数据存储在 `data/filemind.sqlite` 文件中：
- 文件索引（路径、大小、修改时间）
- 文件指纹（SHA256、SimHash）
- 版本链关系
- 用户标记（确认、排除）

删除程序目录即可完全卸载。

## 技术细节

### 版本链识别算法

1. **文件名去噪**：去除版本号、日期、"最终版"等噪声
2. **词干匹配**：同目录下词干相同的文件归为候选组
3. **内容指纹**：通过 SimHash 汉明距离确认是否同一文件的不同版本
4. **置信度**：根据指纹相似度计算置信度，低于阈值标记为"需人工确认"

### 重复文件检测

- 使用 SHA256 计算文件指纹
- SHA256 完全相同的文件视为重复
- 推荐保留最新版本或路径最短的版本

## 注意事项

- 扫描大文件夹可能需要较长时间，可以中途停止
- 删除文件会移入回收站，可以恢复
- 数据库文件不要手动修改，可能导致数据损坏
- 建议定期备份 `data/filemind.sqlite`
